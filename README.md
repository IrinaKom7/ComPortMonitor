# Поверка структуры КМ Честный Знак ручными сканерами
## Описание
ComPortMonitor — специализированное графическое приложение для мониторинга данных, поступающих через виртуальный COM‑порт с от сканера 2D. Основное назначение — проверка структуры кодов Data Matrix, используемых в системе маркировки ГИС МТ, в том числе контроль корректности указания символа‑разделителя ASCII 29 (Group Separator, GS).

Программа позволяет проверять структуру КМ при отладке и тестировании оборудования, работающего со стандартами GS1 DataMatrix: сканеров, принтеров этикеток, а также при разработке и внедрении систем прослеживаемости товаров. ComPortMonitor позволяет в реальном времени наблюдать поток байтов от устройства, выявлять ошибки формирования кода, наличие/отсутствие обязательных разделителей и корректность их использования.

Для корректной структуры кода выводится описание сегментов, их значения и подсвечивается разделитель GS с кодом 29 ASCII.

Некорректные разделители FNC1 с кодом 232 ASCII будут подсвечены красным.

⚠️ **Важно!**
Для определения фактического разделителя необходимо переключить сканер в режим виртуального COM-порта и передачи разделителей "как есть".

## Использование приложения

1. Запустите исполняемый файл:
2. Настройте параметры порта (верхняя панель):
- Port — выберите нужный COM‑порт.
- Baud — скорость передачи (должна совпадать с настройками устройства).
- Data — биты данных (обычно 8).
- Parity — чётность (по умолчанию None).
- Stop — стоп‑биты (по умолчанию One).
3. Нажмите кнопку Connect.
      Программа подключится к порту. В строке статуса появится Connected to <PortName>.
4. При чтении DataMatrix в приложении будут выводится данные:
- Верхняя строка — hex‑коды, нижняя — ASCII‑символы.
  - Байты 1D hex (GS) выделены зелёным — убедитесь, что они присутствуют между полями данных (например, между GTIN, серийным номером, весом).
  - Байты E8 hex (FNC1) выделены красным, что сигнализирует, что процесс нанесения КМ требует корректировки.
- Под сырыми данными будет выводится структура DataMatrix:
  - идентификатор применения AI;
  - содержание идентификатора применения;
  - значение единиц применения (если применимо);
  - длина сегмента. 
5. Сценарий проверки структуры DataMatrix:
- Подключите сканер в USB-порт, выставьте в параметры из п.2.
- Считайте DataMatrix сканером.
- В окне вывода появится информация о считанном коде маркировки.
6. Для остановки нажмите Disconnect. Порт закроется.
7. Для очистки накопленного вывода используйте кнопку Clear.
8. Закрытие программы (крестик в заголовке) автоматически отключается от порта.

Примечание: перед подключением убедитесь, что порт не занят другим приложением (например, терминалом или средой разработки). При ошибке подключения в строке статуса появится сообщение.
